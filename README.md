# ☕ Java Collections Visualizer

Интерактивный визуализатор коллекций Java. Пошагово показывает, что происходит внутри `ArrayList`, `LinkedList`, `HashMap` и `HashSet` при вызове основных методов. Все описания — на русском.

## Что внутри

- 📋 **ArrayList** — add, add(int, E), get, set, remove, contains, size
- 🔗 **LinkedList** — addFirst, addLast, get, removeFirst, removeLast
- 🗺️ **HashMap** — put, get, remove, containsKey (с показом hashCode и коллизий)
- 🎯 **HashSet** — add, contains, remove

## Локальный запуск

```bash
npm install
npm run dev
```
